# User Guide

## Sign In Or Sign Up

Open the app and either log in with an existing account or switch to sign up mode. Password visibility can be toggled with the eye icon.

## Dashboard

The dashboard is the main hub:

- `+` creates a task.
- The trash icon deletes a task by number.
- `Due today` counts tasks with today's deadline.
- `Total tasks` opens the full task board.
- The progress panel shows completed tasks out of the 12 task slots.

## Task Board

The task board shows all current tasks as cards. Each card includes the task name, deadline, relative timing, priority, and progress. Click a card to open its task detail window.

## Creating Tasks

Every task needs:

- Task name
- Deadline, preferably `YYYY-MM-DD`
- Priority from `1` to `3`
- Three subtasks

Priority controls reminder frequency. Higher priority tasks remind you more often.

## Completing Progress

When a reminder appears, enter a completed subtask. If it matches one of the task subtasks, TaskTide updates the progress. When progress reaches completion, the app congratulates you and removes the finished task.
